## Cross-cutting lessons (for future documentation)

1. **Directory reuse caused the worst error (D-3):** `kaggle_analysis/input/` and `Last_run/` names were reused across eras. Always timestamp artifact directories.
2. **Narrative documents (memory exports, history docx) are level-6 evidence** — never the sole basis for a numeric claim (D-4, D-6).
3. **Kaggle "last run" describes only the latest kernel version** (D-14); per-version outputs must be matched by content, not assumed.
