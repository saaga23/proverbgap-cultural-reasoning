# Decision Records

This directory is reserved for **Phase 2 decision records** — durable, dated records of
owner-approved choices about research direction, methodology, data rights, and scope.

Nothing has been decided yet. Do not add decision records until the owner has reviewed
the Phase 1 package (`docs/reconstruction/`, `docs/planning/phase7/`) and the open
questions in `PHASE7_OPEN_QUESTIONS.md` / `DATA_RIGHTS_AND_PROVENANCE.md`.

Suggested format for future records:

```markdown
# DR-NNN: <title>
Date: YYYY-MM-DD   Status: proposed | accepted | superseded
Context: <what needed deciding, with evidence links>
Decision: <what was decided>
Consequences: <what this enables/blocks>
```
